## Reglas para usar estas notas

- **Fuente:** cada dato indica de dónde sale, porque no todos valen lo mismo. Si un dato no está confirmado, se dice.
- **Textos:** aquí van resúmenes con nuestras palabras. No se pegan textos de los libros ni de los compendios.
- **Copias no oficiales:** los escaneos del libro que aparecen en buscadores no se usan como fuente.
- **Vigencia:** las notas del sistema valen para `impmal` 4.1.0. Si se actualiza, hay que comprobarlas otra vez en `referencia\`.
